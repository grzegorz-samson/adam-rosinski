# Adam Rosiński — landing page pack (Astro + Tailwind)

Ten pakiet jest przygotowany jako materiał wejściowy dla asystenta AI lub developera.

Zawiera:
- `01_context_links.md` — linki źródłowe do kontekstu i contentu
- `02_edit_script_for_ai_assistant.md` — gotowy edit-script / prompt wykonawczy
- `03_sitemap_and_wireframe.md` — architektura informacji i opis sekcja po sekcji
- `04_sample_content.md` — przykładowe treści na stronę
- `05_project_tree.md` — sugerowana struktura projektu Astro + Tailwind
- `content/publications_seed.json` — przykładowy seed publikacji
- `content/profile_seed.json` — przykładowy seed danych profilowych

## Rekomendowany workflow
1. Daj asystentowi AI ten pakiet ZIP.
2. Dodatkowo podaj mu publiczne linki źródłowe z pliku `01_context_links.md`.
3. Poproś go o wygenerowanie lub rozwinięcie lokalnego szkieletu projektu Astro + Tailwind.
4. Nie polegaj wyłącznie na live scrapingu źródeł — część stron może się zmienić, a Google Scholar bywa niestabilny dla automatów.

## Dlaczego ZIP + linki to najlepszy układ
- ZIP stabilizuje brief, strukturę i decyzje projektowe.
- Linki pozwalają dociągnąć lub zweryfikować szczegóły publikacji i afiliacji.
- Asystent ma wtedy zarówno *frozen brief*, jak i *live references*.
