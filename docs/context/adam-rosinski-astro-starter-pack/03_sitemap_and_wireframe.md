# Sitemap + wireframe

## Sitemap (MVP)
- `/` — landing page / wizytówka
- `/publications` — lista publikacji
- `/projects` — projekty / studio / praktyka
- `/about` — rozbudowane bio
- `/contact` — kontakt i współpraca

## Priorytet MVP
Na start wystarczy dopracowane `/` oraz dane tak przygotowane, by łatwo było później wygenerować `/publications` i `/projects`.

---

## Wireframe strony głównej

### 1. Header
- logo/wordmark: Adam Rosiński
- nav: Research / Publications / Practice / Contact
- CTA: Explore work

### 2. Hero
- lewa kolumna:
  - imię i nazwisko
  - descriptor
  - lead
  - CTA buttons
- prawa / tło:
  - generatywne pole linii, punktów i fal
  - ma sugerować przepływ, separację i przestrzeń dźwięku

### 3. Research Spectrum
- 5 kart lub segmentów w asymetrycznym układzie
- możliwe obszary:
  - Auditory Scene Analysis
  - Sound Perception
  - Stereo / Surround / Multichannel
  - Recording Technologies
  - Music, Education and Digital Tools

### 4. Auditory Field
- centralny blok o największej „tożsamości wizualnej”
- po lewej przełącznik trybów
- po prawej albo w centrum: dynamiczny SVG
- pod spodem krótki opis aktywnego trybu

### 5. Selected Publications
- sekcja 2x2 lub 1x4 na mobile
- karty publikacji
- opcjonalny link „See all publications”

### 6. Studio / Practice / Technology
- duże zdjęcie lub placeholder visual po jednej stronie
- po drugiej:
  - 1 akapit
  - 3 highlights:
    - studio recording
    - multichannel thinking
    - teaching and technology

### 7. Manifest / Biography
- jeden mocny nagłówek
- 2–3 krótkie akapity
- styl bardziej eseistyczny niż CV-owy

### 8. Contact / Collaboration
- afiliacja
- e-mail
- linki zewnętrzne
- zdanie o współpracy badawczej, artystycznej i edukacyjnej

### 9. Footer
- prosty, spokojny
- copyright / name / external links
